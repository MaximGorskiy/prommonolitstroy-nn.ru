# Проммонолитстрой-НН

Готовая одностраничная визитка промышленного сервиса для GitHub Pages. Откройте `index.html` для просмотра. Сайт работает без сборки, установки зависимостей и сторонних сервисов. Все изображения и стили находятся в этой папке.

## Файлы

- `index.html` — страница, тексты, контакты и реквизиты.
- `styles.css` — оформление для компьютеров и телефонов.
- `assets/industrial.svg` — декоративная техническая иллюстрация, не фотография объекта компании.
- `assets/favicon.svg` — значок сайта.
- `requisites.txt` — реквизиты для скачивания.
- `.nojekyll` — служебный файл для GitHub Pages.

## Размещение

В этой папке создан самостоятельный Git-репозиторий с основной веткой `main` и первым коммитом. Удалённый репозиторий пока не подключён.

Создайте на GitHub пустой публичный репозиторий `prommonolitstroy-nn.ru` без автоматически добавляемых README, .gitignore и лицензии. Затем выполните в этой папке, заменив `ВАШ-ЛОГИН` своим именем на GitHub:

```powershell
git remote add origin https://github.com/ВАШ-ЛОГИН/prommonolitstroy-nn.ru.git
git push -u origin main
```

Загрузите **содержимое этой папки** в корень отдельного репозитория GitHub. Включите GitHub Pages для основной ветки и корневой папки репозитория. `index.html` должен находиться в корне репозитория. Сайт использует относительные пути и подходит для адреса вида `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`.

Папка и сайт компании: `prommonolitstroy-nn.ru`. Домен автоматически не подключён; файл CNAME пока не добавлен.

## Содержание

В качестве стартового описания промышленного сервиса добавлены три направления: техническое обслуживание, ремонтные работы, монтаж и конструкции. Перед публикацией проверьте, соответствуют ли эти формулировки фактическим услугам компании. Сведения о стаже, клиентах, лицензиях и завершённых проектах не добавлены.

Телефон открывает звонок, электронная почта — почтовую программу. Реквизиты раскрываются на странице и скачиваются отдельным текстовым файлом. При изменении реквизитов обновляйте и `index.html`, и `requisites.txt`.
